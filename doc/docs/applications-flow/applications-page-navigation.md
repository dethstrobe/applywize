![screenshot](./test2doc-1757409228180-71.png)

![screenshot](./test2doc-1757409228234-72.png)
![screenshot](./test2doc-1757409228368-73.png)
##### To dismiss the dialog
              ###### Click on the Nevermind button
![screenshot](./test2doc-1757409228683-74.png)

###### Press the escape key
###### Click the X button in the top right of the dialog
![screenshot](./test2doc-1757409230051-75.png)

              Click on the "Yes, Delete it!" button
![screenshot](./test2doc-1757409230769-76.png)

## How to logout

While on the applications page.
Click on logout button.
![screenshot](./test2doc-1757409233464-83.png)
Now you should be logged out and on the login page.
![screenshot](./test2doc-1757409233606-84.png)
To confirm that you are logged out if you try to go back to the applications page (/applications) it will redirect to login.
