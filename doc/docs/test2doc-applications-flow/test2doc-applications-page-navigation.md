While on an application's detail page
![screenshot](./test2doc-1758935768996-71.png)

![screenshot](./test2doc-1758935769057-72.png)
![screenshot](./test2doc-1758935769179-73.png)
##### To dismiss the dialog
              ###### Click on the Nevermind button
![screenshot](./test2doc-1758935769499-74.png)
###### Click outside of the dialog
###### Press the escape key
###### Click the X button in the top right of the dialog
![screenshot](./test2doc-1758935770876-75.png)

              Click on the "Yes, Delete it!" button
![screenshot](./test2doc-1758935771624-76.png)

## How to logout

While on the applications page.
Click on logout button.
![screenshot](./test2doc-1758935773453-83.png)
Now you should be logged out and on the login page.
![screenshot](./test2doc-1758935773599-84.png)
To confirm that you are logged out if you try to go back to the applications page (/applications) it will redirect to login.
