The table should populate with active applications.
![screenshot](./test2doc-1761165718677-39.png)

![screenshot](./test2doc-1761165718791-40.png)

![screenshot](./test2doc-1761165719020-41.png)

![screenshot](./test2doc-1761165719105-42.png)
