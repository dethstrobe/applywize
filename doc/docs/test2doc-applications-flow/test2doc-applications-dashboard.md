## Filter between active and archived applications

Navigate to applications page.
The table should populate with active applications.
![screenshot](./test2doc-1760987963680-39.png)

![screenshot](./test2doc-1760987963767-40.png)

![screenshot](./test2doc-1760987963900-41.png)

![screenshot](./test2doc-1760987964023-42.png)
Now active applications should be displayed again.
