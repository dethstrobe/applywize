# Create a new application

## Create a new application

While on the applications page
Click on new application button
![screenshot](./test2doc-1760987952035-1.png)
### New Application page
                You should have navigated to the New Application page where you can fill out the company information form
![screenshot](./test2doc-1760987952218-2.png)
#### Enter the company name
![screenshot](./test2doc-1760987952340-3.png)
#### Enter the job title
![screenshot](./test2doc-1760987952412-4.png)
#### Enter the job description
![screenshot](./test2doc-1760987952480-5.png)
#### Enter the salary range
![screenshot](./test2doc-1760987952548-6.png)
![screenshot](./test2doc-1760987952612-7.png)
#### Enter the application URL
![screenshot](./test2doc-1760987952681-8.png)
#### Enter the date intended to apply to this company
![screenshot](./test2doc-1760987952744-9.png)
Click the date button to open the date picker.
![screenshot](./test2doc-1760987952887-10.png)
Select a date from the date picker.
![screenshot](./test2doc-1760987953208-11.png)
Click outside of the date picker or press escape to close it.
![screenshot](./test2doc-1760987953708-12.png)
#### Select one of the Application Statuses
![screenshot](./test2doc-1760987953741-13.png)
Click the Application Statuses button to open the dropdown
![screenshot](./test2doc-1760987953857-14.png)
Select one of the application statuses from the dropdown
![screenshot](./test2doc-1760987954131-15.png)
#### Add a Contact for the Application
                Open the Add a Contact sheet by clicking the "Add a contact" button.
![screenshot](./test2doc-1760987954230-16.png)
##### Enter the First Name of the contact
![screenshot](./test2doc-1760987954341-17.png)
##### Enter the Last Name of the contact
![screenshot](./test2doc-1760987955306-18.png)
##### Enter the contacts role in the company
![screenshot](./test2doc-1760987955381-19.png)
##### Enter the contacts email address
![screenshot](./test2doc-1760987955449-20.png)
##### Add the contact by clicking the "Create a Contact" button
![screenshot](./test2doc-1760987955511-21.png)
Your new contact appears on the Contacts section
![screenshot](./test2doc-1760987956472-22.png)
#### Submit the form
![screenshot](./test2doc-1760987956527-23.png)
You should be redirected to the Applications page where you can see your new application.
![screenshot](./test2doc-1760987956773-24.png)
